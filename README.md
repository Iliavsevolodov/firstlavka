# ПЕРВАЯ ЛАВКА

Тестовый промо-сайт будущего магазина свежих продуктов в Соколе.

## Бренд
- Название: **ПЕРВАЯ ЛАВКА**
- Слоган: **Выбираем как для себя**
- Дескриптор: овощи • фрукты • специи • продукты
- Цвета: #3F5130, #F5F0E6, #C96B4B, #2B2B2B, #A8B79A
- Шрифты: Onest + Manrope

## Что реализовано
- адаптивная главная страница;
- блоки ассортимента и преимуществ;
- сезонные позиции;
- концепция «Корзина недели»;
- тестовая форма интереса;
- мобильное меню;
- фирменный favicon.

## Запуск
Откройте `index.html` локально или опубликуйте репозиторий через GitHub Pages.

> Форма на текущем этапе демонстрационная и не отправляет данные.
