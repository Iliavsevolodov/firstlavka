# ПЕРВАЯ ЛАВКА

Тестовый промо-сайт бренда современной городской лавки свежих продуктов.

## Концепция бренда
- **Название:** ПЕРВАЯ ЛАВКА
- **Слоган:** Выбираем как для себя
- **Дескриптор:** овощи • фрукты • специи • продукты
- **Основные цвета:** #3F5130, #F5F0E6, #C96B4B, #26351D
- **Шрифты:** Onest + Manrope

## Визуальная концепция сайта
Редизайн построен как сайт уже сформировавшегося retail-бренда:
- полноэкранный editorial hero;
- фирменный знак «1»;
- премиальная фото-подача;
- bento/editorial-сетка;
- блок свежих поступлений;
- ассортимент по категориям;
- философия отбора продукта;
- концепция «Корзина недели»;
- адаптивная мобильная версия;
- scroll-reveal и микроанимации;
- фирменный favicon;
- GitHub Pages deployment.

## Файлы
- `index.html` — структура сайта;
- `styles.css` — дизайн-система и адаптив;
- `script.js` — меню, анимации и демо-форма;
- `favicon.svg` — знак бренда;
- `.github/workflows/pages.yml` — публикация через GitHub Pages.

> Контактная форма в текущей тестовой версии не отправляет данные на сервер.
